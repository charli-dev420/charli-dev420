## Featured project

### 🎛️ [DAWWW-CORE](https://github.com/charli-dev420/Daw-core-desktop)

**Local-first browser DAW — Desktop available now without payment.**

DAWWW-CORE combines a sequencer, piano roll, arranger, mixer, automation and audio export with **51 built-in instruments** and **16 built-in effects**. Projects remain portable through the `.dw` format, with the upcoming Android subscription version designed as a **100% cross-device continuation of the same Desktop project**.

[Public GitHub showcase](https://github.com/charli-dev420/Daw-core-desktop) · [Open Desktop Studio](https://dawww-core-local.com/app) · [Documentation](https://dawww-core-local.com/en/docs)

`Web Audio` · `AudioWorklet` · `TypeScript` · `React` · `Local-first` · `Cross-device`
